## Declaración

El frontend del sistema debe implementarse con React (TypeScript) como PWA.

## Racional

React es el estándar del equipo para interfaces web. Combinado con Vite y
librerías modernas (TanStack Query, Zustand, shadcn/ui) permite desarrollo
rápido de una PWA mobile-first.

## Artefactos de implementación

### Frontend
- `front/package.json` — dependencias React
- `front/vite.config.ts` — configuración Vite + PWA
- `front/src/App.tsx` — componente raíz
- `front/src/main.tsx` — entry point
- `front/src/routes.tsx` — enrutador
- `front/src/features/` — features del dominio
