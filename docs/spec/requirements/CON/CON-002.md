## Declaración

El backend del sistema debe implementarse con NestJS (Node.js/TypeScript).

## Racional

NestJS proporciona una arquitectura modular con soporte nativo para DDD,
CQRS, inyección de dependencias, guards de autenticación, y OpenAPI.

## Artefactos de implementación

### Backend
- `back/package.json` — dependencias NestJS
- `back/src/main.ts` — bootstrap
- `back/src/app.module.ts` — módulo raíz
- `back/src/modules/` — módulos del dominio
- `back/tsconfig.json` — configuración TypeScript

## Notas

- Restricción definida desde el inicio del proyecto.
- La arquitectura sigue ADR-2026-07-06 (modular monolith DDD + CQRS).
