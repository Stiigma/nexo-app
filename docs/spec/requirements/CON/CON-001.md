## Declaración

El producto debe ser una PWA (Progressive Web App), no una aplicación nativa
iOS o Android, para la versión v1.

## Racional

Una PWA cumple con los requisitos mobile-first sin necesidad de desarrollar y
mantener dos apps nativas separadas. Además, una PWA se puede instalar en el
home screen del celular y funciona sin pasar por las app stores.

## Artefactos de implementación

### Frontend
- `front/vite.config.ts` — configuración de PWA (vite-plugin-pwa)
- `front/index.html` — manifest link y service worker
- `front/public/` — iconos y assets PWA
- `front/src/main.tsx` — registro de service worker

## Notas

- Restricción arquitectónica no negociable para v1.
