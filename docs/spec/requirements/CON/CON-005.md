# CON-005: Fotos en S3-compatible

| **Fuente** | `NEXO_PROJECT.md` §3 — Stack base |

## Declaración

Las fotos de prendas deben almacenarse en storage S3-compatible, no en
PostgreSQL.

## Racional

Los archivos binarios grandes degradan el rendimiento de la base de datos
relacional. Usar S3-compatible separa responsabilidades y escala mejor.
