## Declaración

La base de datos del sistema debe ser PostgreSQL.

## Racional

PostgreSQL ofrece robustez transaccional, soporte JSON, tipos enum, índices
parciales y excelente rendimiento para cargas de trabajo relacionales como las
que requiere Nexo (compras, ventas, inventario, relaciones).

## Artefactos de implementación

### Backend
- `back/prisma/schema.prisma` — esquema de base de datos (Prisma ORM)
- `back/prisma/migrations/` — migraciones
- `back/.env` — `DATABASE_URL`

### Infraestructura
- Docker Compose (local) o servicio administrado (producción)

## Notas

- Restricción definida desde el inicio del proyecto.
- Se usa Prisma como ORM sobre PostgreSQL.
