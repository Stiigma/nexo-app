# CON-007: Internet y HTTPS en producción

|---|---|

| **Fuente** | `NEXO_PROJECT.md` §11 — Supuestos base |

## Declaración

La versión v1 requiere conexión a internet para operar y debe usar HTTPS en
producción.

## Racional

Sin conexión a internet el frontend no puede comunicarse con el backend. HTTPS
es necesario para cifrar datos financieros y de clientes, y es requisito para
PWA.

## Artefactos de implementación

### Backend
- `back/src/main.ts` — configuración CORS y HTTPS
- Infraestructura de deploy
- `back/.env` — variables de entorno

### Frontend
- PWA service worker (offline no soportado en v1)

## Notas

- Modo offline está explícitamente fuera del alcance de v1.
- NFR-SEC-001 complementa con la redirección HTTPS.
