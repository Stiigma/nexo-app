## Declaración

El sistema debe integrarse con almacenamiento S3-compatible para subir,
almacenar y servir las fotos de las prendas.

## Racional

Las fotos son el elemento más pesado del sistema. Un storage externo dedicado
es más eficiente y escalable que PostgreSQL.

## Criterio de Aceptación

- Dado que subo una foto,
  cuando la operación se completa,
  entonces el archivo está accesible en el storage y tengo una URL para
  recuperarlo.

## Método de Verificación

- [ ] Demo: Subir foto y verificar que se almacena en S3.
- [ ] Prueba de integración: upload y download desde storage.

## Artefactos de implementación

### Backend
- Módulo NestJS: `back/src/modules/media/`
  - `application/ports/file-storage.port.ts` — puerto abstracto
  - `infrastructure/adapters/azure-blob-storage.adapter.ts` — Azure Blob (S3-compatible)
  - `infrastructure/adapters/local-storage.adapter.ts` — local para dev
  - `application/services/upload-media.usecase.ts` — caso de uso de subida
  - `application/services/resolve-item-photo-read-url.usecase.ts` — resolución de URL
  - `interface/http/media.controller.ts` — endpoints REST
