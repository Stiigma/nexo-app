## Declaración

El proveedor recomendado para tipo de cambio USD→MXN es Banxico SIE (FIX),
sujeto a validación de factibilidad técnica durante la implementación.

## Racional

Banxico es la fuente oficial del tipo de cambio en México. Usar datos oficiales
aumenta la confiabilidad de los reportes financieros.

## Criterio de Aceptación

- Dado que Banxico SIE/FIX es viable técnicamente,
  cuando se configura como proveedor,
  entonces el sistema obtiene la tasa FIX diaria.

## Método de Verificación

- [ ] ADR que documenta la selección del proveedor antes de implementación.
- [ ] Prueba de integración: conexión con Banxico SIE API.
