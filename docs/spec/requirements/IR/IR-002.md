## Declaración

El sistema debe obtener el tipo de cambio USD→MXN de forma automática para
cálculos financieros, o permitir captura manual como fallback.

## Racional

El negocio opera con compras en USD. Sin tipo de cambio automático, el operador
tendría que buscarlo manualmente, lo que retrasa la captura y puede causar
errores.

## Criterio de Aceptación

- Dado que se crea un carrito en USD,
  cuando el sistema intenta obtener el tipo de cambio,
  entonces lo obtiene automáticamente de un proveedor o permite al operador
  ingresarlo manualmente.
