## Declaración

Las correcciones administrativas a datos operativos deben preservar suficiente
contexto para entender qué cambió, cuándo y quién lo hizo.

## Racional

Sin auditoría, una corrección accidental o maliciosa puede pasar desapercibida
y corromper los datos financieros sin posibilidad de trazabilidad.

## Criterio de Aceptación

- Dado que un admin realiza una corrección,
  cuando la operación se completa,
  entonces queda un registro con: usuario, fecha, campo anterior, campo nuevo.
