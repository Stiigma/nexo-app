## Declaración

Las fotos de prendas deben almacenarse en storage S3-compatible. PostgreSQL
almacena solo metadatos y URLs de referencia.

## Racional

Las fotos son archivos grandes. Almacenarlos en PostgreSQL degradaría el
rendimiento de las consultas y aumentaría el tamaño de la base de datos
innecesariamente.

## Criterio de Aceptación

- Dado que subo una foto de prenda,
  cuando la operación se completa,
  entonces el archivo binario está en S3-compatible y en PostgreSQL solo hay
  una URL o referencia.
