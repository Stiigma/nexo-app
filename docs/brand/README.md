## Visual Direction

- Use the supplied horizontal Nexo logo as the primary brand reference.
- Preserve the black background, white italic wordmark, and electric-blue slash
  as the strongest brand signals.
- For the disposable prototype, prefer a restrained operational UI that uses
  the blue accent selectively for primary actions, active states, and focus.
- Do not overbuild a marketing-style landing page for the prototype. The first
  screen should remain the usable purchase-capture workflow.

## Prototype Usage

- Use the logo in the prototype shell/header where it helps orient the user.
- Keep the logo legible on small mobile widths; avoid squeezing or cropping the
  wordmark.
- If a compact mark is needed later, create a separate derived asset instead of
  cropping this source ad hoc.
