# Nexo QA Checklist

- Requirement, acceptance criterion, and test/evidence traceability is complete.
- Focused verification was run independently or an exact block is recorded.
- Commands, results, and exit status are present.
- Negative paths, data integrity, permissions, UX states, and accessibility were considered.
- Architecture/pattern adherence, smells, and maintenance delta were reviewed.
- QA did not fix its own findings.
- Release readiness covers smoke checks, rollback trigger, recovery owner, and residual risk when production is in scope.
