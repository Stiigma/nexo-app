# fiad-infra Checklist

- Read affected Project Profile, workspace map, infra files, and current task.
- Formal infra gate is required for shared Docker, K8s, CI/CD, routing, deploy
  scripts, or Harness automation changes.
- Keep local/staging/production parity explicit.
- Do not deploy, push, or change external environments without confirmation.
- Close with verification evidence, gate decision, and report.
