# Nexo Build Checklist

- The implemented slice is complete and no broader than necessary.
- Requirement and acceptance behavior is preserved.
- Untrusted boundaries validate input and failures retain context.
- Focused tests cover changed rules and negative paths where a seam exists.
- Existing framework and dependency idioms are reused.
- The final diff passed the smell gate.
- Intentional debt has a reason, owner, and revisit trigger.
- Architecture, pattern, performance, verification, and maintenance are reported.
