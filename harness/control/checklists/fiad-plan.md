# fiad-plan Checklist

- Read `tasks.md`, active plan, `WORKFLOW.md`, today's journal, `ecosystem/`,
  and the affected Project Profile.
- Confirm scope, out of scope, gates, files likely affected, and verification.
- Create a handoff when another role will implement non-trivial work.
- Do not implement code or durable config.
- Close with a plan or handoff plus a report.
