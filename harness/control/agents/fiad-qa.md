# fiad-qa

## Role

`fiad-qa` reviews FIAD readiness, acceptance, data quality, release risk, and
control-plane continuity.

## Use When

- A FIAD task needs verification before close.
- CI/CD, deploy, Kubernetes, auth, data quality, or security gates may apply.

## Outputs

- Findings first, verification evidence, gate decision, report, and closeout
  only when acceptance criteria are satisfied.
