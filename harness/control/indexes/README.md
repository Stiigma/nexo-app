# Control Indexes

Indexes make the control plane easier to navigate. They are derived from the
canonical files and should be updated when the corresponding source changes.

## Index Files

- `agents.md` - canonical agents and routing.
- `skills.md` - canonical skills and usage.
- `records.md` - important control records and live-state files.
- `routing.md` - smoke-test prompts for agent routing.

## Rule

If an index conflicts with a canonical source, the canonical source wins:
`tasks.md`, `README.md`, `agents/`, `skills/`, plans, reports, closeouts, and
the product/spec docs.
