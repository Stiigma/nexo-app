# Investigations

Investigations record debugging, diagnosis, research, and unknowns before
implementation.

## Use When

- The cause of a defect is unclear.
- Multiple implementation paths need evidence.
- A future handoff depends on diagnostic findings.

## Required Content

- Question or symptom.
- Context.
- Evidence gathered.
- Findings.
- Ruled-out causes.
- Recommended next step.
- Follow-up handoff, if any.
