# Runbooks

Runbooks describe repeatable operational procedures for local development,
deployment, recovery, and maintenance.

## Use When

- A human or agent needs repeatable operational steps.
- Infrastructure changes introduce a procedure or rollback path.
- A release or migration requires manual coordination.

## Required Content

- Purpose.
- Preconditions.
- Inputs.
- Steps.
- Verification.
- Rollback.
- Escalation.
- Related ADRs, tasks, and reports.
