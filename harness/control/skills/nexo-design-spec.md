# nexo-design-spec

## Purpose

Create UX/UI design specifications for visible product changes.

## Required Coverage

- Users, roles, and permissions.
- Screens and navigation.
- Primary workflows.
- Form fields, validation, and errors.
- Empty, loading, error, disabled, and permission states.
- Responsive behavior.
- Accessibility expectations.
- Copy and terminology.

## Output

Record the design in the active plan, a handoff, or a dedicated design report.
Link it from the task plan so `nexo-build` and `nexo-qa` can verify against it.

## Verification

Confirm every user-facing acceptance criterion has a visible state or flow that
can be tested.
