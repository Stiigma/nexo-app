# Implementations

Implementation records capture durable context for code, config, or operational
behavior changes.

## Use When

- Code or config changes affect future development.
- Operational behavior, scripts, or infrastructure conventions change.
- A future agent would need more context than a terse report provides.

## File Name

```text
NEXO-0000-short-title.md
```

## Required Content

- Task ID.
- Date.
- Summary.
- Files changed.
- Behavior changed.
- Verification.
- Operational notes.
- Follow-up.
